# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |

## Reporting a Vulnerability

To report a vulnerability, please open a [GitHub Security Advisory](https://github.com/valdomirogalo/EdiHybridCache/security/advisories/new).

- **Author**: Valdomiro Galo ([ORCID](https://orcid.org/0009-0009-0862-1462))
- **Response time**: You can expect an initial response within 48 hours.
- **Disclosure**: We follow coordinated disclosure. Please do not disclose vulnerabilities publicly before a fix is released.
